## 2 · A2 天赋法术同步 → 父页消息中继(优于昨日方案)

**根因(实测细化)**:blob iframe 内 `parent.frames.length===undefined`,`for(var i=0;i<p.frames.length;i++)` 一次都不执行且**不抛异常**;`p.postMessage(data,'*')` 把消息送达父页,但父页无人监听。两个工具其实都已经在"朝父页喊话",缺的只是父页转发。

**为什么不用昨日的 `parent.document` 寻帧方案**:`file://` 下 blob iframe 源为 null,实测从 iframe 访问 `parent.document` 抛 SecurityError——该方案只救 http,救不了 file:// 双击场景。**父页中继**两种场景通吃:`postMessage('*')` 跨源可用,父页访问自家 iframe 的 `contentWindow.postMessage` 也不受限。

**修复(只改 build.js 模板,三工具源码零改动)** —— build.js 合集模板 `<script>` 末尾(约 140 行 `tg.addEventListener` 之后)追加:

```js
// A2 消息中继:子 iframe 的 postMessage 只能直达父页,由父页转发给兄弟 iframe。
// postMessage('*') 跨源可用(blob iframe 在 file:// 下源为 null 也能通),兼容 http/file 双场景。
window.addEventListener('message', function(e){
  var d = e.data;
  if (!d || !d.type) return;
  if (d.type !== 'dnd:granted' && d.type !== 'dnd:requestGranted') return;
  ['spellbook', 'adventurer', 'items'].forEach(function(id){
    var f = document.getElementById(id);
    if (f && f.contentWindow && f.contentWindow !== e.source) {
      try { f.contentWindow.postMessage(d, '*'); } catch (err) {}
    }
  });
});
```

原理闭环:
- 人物卡 `broadcastGranted()` 既有 `p.postMessage(data,'*')`(2862 行)→ 父页中继 → 法术书 `applyGrantedMessage` 收到入卡 ✓
- 法术书 `requestGrantedSpells()` 既有 `p.postMessage(msg,'*')`(app.js:700)→ 中继 → 人物卡 2928 行监听器应答 `e.source.postMessage(...)`(直达,无需中继)✓
- items 无监听,收到无害。

**可选加固**(不必须):两处 `catch{}` 各补 `console.warn`,别再静默。

**验证**:①合集页建提夫林(炼狱)→ 切法术书 → 「已从角色卡同步 2 个天赋法术」且 奇术/火焰箭入卡;②`file://` 双击合集重复①;③法术书先打开、后建人物卡 → 刷新法术书(请求握手)也能补同步。
